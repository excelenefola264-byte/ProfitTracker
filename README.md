# ProfitTrack

## Overview

ProfitTrack is a small business financial management system developed to help business owners manage their business operations and financial records in one place.

The system provides tools for managing products, monitoring inventory, recording sales and tracking expenses. It also presents business information through a dashboard and reports, helping users understand their business performance.

## Features

- **Dashboard:** Provides an overview of sales, expenses, net profit and available stock.
- **Business Setup:** Allows users to enter their business information.
- **Products:** Enables users to add and manage products.
- **Inventory:** Helps monitor stock levels.
- **Sales:** Records business sales.
- **Transactions:** Keeps track of financial transactions.
- **Reports:** Presents business performance information.
- **Settings:** Provides business configuration options.

## Technologies Used

- React
- JavaScript
- CSS
- Python
- Django
- Django REST Framework
- SQLite

## Project Purpose

ProfitTrack aims to simplify recordkeeping for small businesses by bringing important business management activities together in one system.
